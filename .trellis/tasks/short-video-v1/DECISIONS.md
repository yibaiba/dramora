# 🎯 关键技术决策记录 (ADR)

## 决策 1: 优先做虚拟主播（HeyGen）而不是图像生成

**背景**: 
- 原方案: 图像 + 视频 + 文案 + 音乐 + 动画 (6-7 周)
- 市场调研发现: HeyGen 虚拟主播在电商短视频中效果最好

**决策**:
✅ MVP v1 用 HeyGen 虚拟主播
❌ 图像生成 (Comfy UI) 推迟到 v2

**原因**:
1. 效果最自然 (真人级)
2. 最容易吸引用户
3. 可直接替代真人演员
4. 节省 1-2 周工期
5. 降低 MVP 复杂度

**影响**:
- 工期: 6-7 周 → 5.5 周
- 功能性完整性: 不变
- 用户体验: 更好 (虚拟主播更炫酷)
- 成本: 约 $50-200/月 (HeyGen API)

**替代方案**:
- A: 图像 + 视频 (原方案) - 太复杂
- B: 只用文案/预设 - 效果太差
- C: ✅ 虚拟主播 (选择)

## 决策 2: 预设音乐库而不是 Suno AI 生成

**背景**:
- 原计划: Suno AI 生成背景音乐
- 成本: $10/月 + API 调用
- 复杂度: 额外 1 周工期

**决策**:
✅ MVP v1 用预设音乐库 ($0)
❌ Suno 推迟到 v2

**原因**:
1. 成本: $0 vs $10+/月
2. 速度: 无需生成，直接选择
3. 质量: 预设音乐经过审核
4. 工期: 节省 3-5 天

**影响**:
- 成本: 节省 $10/月
- 工期: 节省 3-5 天
- 用户体验: 略微下降 (无定制)

**替代方案**:
- A: Suno 生成 - 太贵
- B: ✅ 预设库 (选择)
- C: 无背景音 - 体验太差

## 决策 3: Claude 文案生成而不是 GPT

**背景**:
- 考虑使用: GPT-4 vs Claude
- Dramora 已在使用 Claude

**决策**:
✅ 使用 Claude (Haiku or Sonnet)

**原因**:
1. 成本更低 (Haiku 最便宜)
2. 质量够好 (电商文案)
3. 已在项目中使用 (不需要新接入)
4. API 文档完善

**影响**:
- 成本: 低于 GPT
- 集成: 现有知识复用
- 维护: 一致的 LLM 选择

---

## 决策 4: HeyGen 虚拟主播风格

**背景**:
- HeyGen 提供多种虚拟主播
- 选择: 亚洲人物 vs 欧美人物

**决策**:
✅ 初期提供 2-3 种虚拟主播选择
  - 1 个专业女性 (电商主播风格)
  - 1 个专业男性 (产品讲解风格)
  - 1 个年轻风格 (潮流卖家风格)

**原因**:
1. 满足不同电商风格
2. 初期不需要太多选择 (避免选择过载)
3. v2 再添加更多角色

**影响**:
- 用户体验: 个性化选择
- 工期: 无额外影响 (HeyGen API 内置)
- 成本: 无额外成本

## 决策 5: 初期 2-3 个模板（后续扩展）

**背景**:
- 原计划: 5 个模板 (MVP)
- 时间压力: 需要快速上线

**决策**:
✅ MVP v1: 2-3 个核心模板
  - 商品聚焦 (虚拟主播展示) ⭐ 最重要
  - 活动推广 (虚拟主播讲解) ⭐ 转化最高
  - 使用场景 (虚拟主播演示) ⭐ 教育性

❌ 暂不做: 多品对比, 开箱测评 (v1.1)

**原因**:
1. 80% 用户需求 (20% 功能)
2. 节省模板设计时间
3. 快速验证市场
4. v1.1 基于反馈扩展

**影响**:
- 工期: 节省 2-3 天
- 功能性: MVP 无缺陷
- 用户满意度: 依然高 (核心模板全覆盖)
- 扩展性: 非常好 (只需新增模板配置)

## 决策 6: 技术栈选择

### 后端
- **数据库**: 现有 PostgreSQL
- **语言**: Go (现有)
- **API 框架**: Chi (现有)

### 前端
- **框架**: React (现有)
- **状态管理**: Zustand (现有)
- **UI 组件**: 现有 UI 库

### AI 集成
- **虚拟主播**: HeyGen API
- **文案**: Claude API (现有)
- **音乐**: 预设库 + S3 存储

### 视频处理
- **Timeline**: 现有 Timeline 系统
- **编码**: FFmpeg (现有)

**原因**: 最大化复用现有系统，降低集成成本

## 决策 7: MVP 工期承诺

**决策**:
✅ 5.5 周可交付 MVP

**分解**:
- Week 1: 模板 + API (1 周)
- Week 2: HeyGen (1 周)
- Week 3: 文案 + 前端 (3 天)
- Week 4: 导出 + 合成 (1 周)
- Week 5: 测试 + 优化 (0.5 周)

**风险**:
- HeyGen API 文档 / 延迟
- Claude API 限流
- FFmpeg 编码时间

**缓冲**: 交叉日期容许 1 周灵活度
